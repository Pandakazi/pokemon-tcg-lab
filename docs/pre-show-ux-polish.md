React escapes HTML; no arbitrary HTML, executable links or raw-output interpretation was introduced. Existing metadata guards and exact card preview behavior remain intact. This is a bounded Markdown subset, not a full Markdown engine.
6. **Copy Deck List.** Generated/proposed resolved lists offer a small copy action with a two-second Copied confirmation and a concise clipboard failure message. Plain text contains category totals, exact names/counts, exact TCGdex printing IDs and total count. A diff copies its resulting resolved list. Partial lists explicitly say only resolved cards are copied. No reusable web PTCGL exporter/importer was found; this is plain text and does not claim native PTCGL import compatibility.
7. **Catalog-wide illustrator discovery.** Illustrator names come from existing raw TCGdex metadata. Gallery artist filters enumerate every matching exact TCG printing across the entire local catalog, including historical/not-Standard printings, Pokémon/Trainer/Energy and owned/unowned cards. They bypass the competitive Library's default Standard restriction, functional representative grouping, category/ownership/classification constraints and preferred-printing substitution. Pagination counts exact printings. Card Detail links open a fresh Gallery URL containing only the artist filter, including when entered from Collection or Deck Builder. Normal Library/Collection browsing remains unchanged. General search additionally recognizes illustrator text; the exact artist selection is the catalog-wide mode. No artist database, profiles or external links were added.
